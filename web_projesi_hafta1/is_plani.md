# Proje İş Planı ve Takvimi (Work Packages)

Projemiz, dersin resmi takvimine ve gereksinimlerine uygun olarak aşağıdaki 5 temel iş paketine (WP) bölünmüştür.

## İş Paketleri

| İş Paketi | Kapsam ve Yapılacaklar | Hedeflenen Tarih |
| :--- | :--- | :--- |
| **WP1: Hazırlık ve Konu Sunumu** | GitHub reposunun açılması, gereksinim (`gereksinimler.md`) ve problem (`PROBLEM.md`) dosyalarının hazırlanması. Sınıf içi konu sunumunun (7 dk) yapılması. | 1. ve 2. Hafta (13 Ekim'e kadar) |
| **WP2: Backend ve Veritabanı** | C# .NET Core Web API iskeletinin kurulması, MS SQL Server tablolarının (Users, Items, Categories) oluşturulması. ASP.NET Identity ile rol tabanlı yetkilendirmenin (Admin/Kullanıcı) yazılması. | 3. ve 4. Hafta |
| **WP3: Frontend ve Ekstra Özellikler** | React (Vite) kullanılarak etkileşimli kullanıcı arayüzünün kodlanması. İlanlara görsel/dosya yükleme modülünün ve Admin paneli için grafiksel raporlama ekranlarının entegrasyonu. | 4. ve 5. Hafta |
| **WP4: Yayın (Deploy) ve Canlı Sunum** | Projenin backend ve frontend kısımlarının herkese açık bir sunucuda (Vercel, Render vb.) canlıya alınması. İlk proje sunumu için sistemin hazır hale getirilmesi. | 6. Hafta (10 Kasım'a kadar) |
| **WP5: Test, Bug Hunting ve Final** | Projenin %100 tamamlanması. Karşılıklı test ekibinin bulduğu açıkların (Issue) tespit edilmesi ve bu hataların Pull Request (PR) yöntemiyle kapatılıp onaylanması. | 8. - 10. Hafta (8 Aralık'a kadar) |

## Ekstra Özellikler (Bonus) Planlaması
Slaytlarda belirtilen ve projede yer alacak zorunlu ekstra özellikler[cite: 14]:

2. **Görsel Yükleme:** Bulunan eşyaların fotoğraflarının sisteme yüklenmesi (WP3'te uygulanacak)[cite: 14].
3. **Raporlama/Grafik:** Sistemdeki eşyaların aylara ve kategorilere göre dağılım grafiği (WP3'te uygulanacak)[cite: 14].
